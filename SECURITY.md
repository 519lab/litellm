# Security Policy

> **This is 519lab's fork of LiteLLM.** Report vulnerabilities in this fork's own changes (anything listed in `CHANGELOG.md`, the fork's CI, install scripts and releases) privately through this repository's **Security** tab and **Report a vulnerability**. Report vulnerabilities in upstream LiteLLM code to BerriAI through the [LiteLLM vulnerability disclosure form](https://security.litellm.ai/vdp/), not here

Reports for this fork follow the [519lab security policy](https://github.com/519lab/.github/blob/develop/SECURITY.md), which sets the response timeline, coordinated disclosure, safe harbor and scope

If you are not sure which side a problem is on, report it here and we will route it. Never report a vulnerability in a public issue, discussion or pull request
